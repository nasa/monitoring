# InterUss Position Reporter Instance Requirements

## Overview

These requirements apply to a test participant providing a hosted instance of InterUSS's Position Reporter.

## Requirements

### <tt>ExposeInterfaceAndProvideFunctionality</tt>

A test participant providing a hosted instance of InterUSS's Position Reporter must expose all endpoints implemented by position_reporter, as configured by the test participant, appropriate to the tests being performed.  All position_reporter endpoints necessary for the tests being performed must be exposed and must behave according to the InterUSS codebase version appropriate to the tests.
